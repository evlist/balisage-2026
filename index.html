How does it work

Web workflow: Wordpress blog with custom plugin and theme.

Print workflow: PDF pages printed from Wordpress and assembled into books.

Video workflow: MP4 videos exported from Wordpress and uploaded to YouTube.

No automation between video and text.

But...

Web and print are different.

The same content needs different presentations.

CSS print is not enough.

CSS can't change the structure of the content.

That's why XSLT has been invented.

Wordpress doesn't use XSLT.

Wordpress block templates

In 2028, Wordpress introduced block (and page) templates.

Block templates are a way to change the structure of the content.

They are written in PHP and HTML.

They can be used to create different presentations of the same content.

Need to attach different page templates for web and print.

Done adding a "?print" query string.

A PHP hack selects a page template with a "-print" suffix when "?print" is detected.

Completely different presentations can be used for web and print.

Current and future directions

Package these hacks into proper plugins.

AI

This year I have started using AI (claude).

Inputs: video subtitles, GPX tracks and proper prompts.

Outputs: technical hiking guides, narrative and an additional educational section.

HTML formatted, the output can be directly pasted into Wordpress.

Game changer

AI can generate content from video subtitles and GPX tracks.

It could also generate content for different presentations (web, print, video).

It could also generate content for different audiences (friends, relatives, mother).
